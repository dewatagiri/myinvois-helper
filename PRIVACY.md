# MyInvois Helper — Privacy Policy

_Last updated: 3 October 2026 (logging wording corrected)_

MyInvois Helper is a free tool by PintuNiaga that helps Malaysian businesses draft and check LHDN e-invoices inside AI assistants such as Claude and ChatGPT. This policy explains what happens to the information you give it.

## 1. What we collect

- **Invoice details you type in** (business names, TIN, BRN, SST number, addresses, phone numbers, line items, amounts). These are sent to the tool only to calculate the draft and are **not stored**.
- **Basic server logs**: one line per request containing only the **time of the request, the function called** (for example `tools/call`, or a page such as `GET /health`) **and the response status** (for example 200). Our logs do **not** contain IP addresses, session IDs, sign-in details, web-address parameters, or any invoice contents, names, tax numbers, ID numbers or amounts.
- **Short-lived request counters**: to stop abuse, the server counts requests per IP address and per session ID in memory for up to one minute. These counters are never written to logs or disk and disappear when the minute ends or the server restarts.
- We do **not** use cookies, user accounts, passwords, analytics or advertising trackers.

## 2. How we use it

Inputs are processed in memory to return the invoice draft, SST totals, classification-code suggestions and readiness checklist. Nothing is used for marketing, profiling or AI training.

## 3. Storage and retention

- **The tool does not store invoice drafts, buyer details or ID numbers** (MyKad, MyTentera, MyPR, MyKAS, passport or business registration numbers). They exist in server memory only while your request is processed (usually under one second) and are then gone.
- Our server logs (the lines described above) are collected by our hosting provider, Render, and kept for a limited period under its standard log retention, then deleted automatically.
- Our hosting provider, Render, may keep its own standard server logs, which can include IP addresses, under its own privacy policy.

## 4. Sharing

We do not sell, rent or share your information. The tool does **not** submit anything to LHDN or any other party. Our hosting provider (Render, Inc.) runs the server and may process request metadata, such as IP addresses, under its own privacy policy.

The AI assistant you use (for example Claude or ChatGPT) has its own privacy policy covering your conversation.

## 5. Security

All traffic uses HTTPS. The tool keeps no database of user data, so there is no stored invoice data to leak.

## 6. Your choices

You can stop using the tool at any time by disconnecting it in your AI assistant's settings. Because we keep no invoice data, there is nothing to delete.
